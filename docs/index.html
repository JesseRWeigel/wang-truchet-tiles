Wang and Truchet tiles

Squares with coloured edges, placed without rotation so that touching edges agree. Curves that join because the geometry makes them join, checked rather than asserted. Every tiling here is reproducible from its seed.

The triangles show the edge colours themselves, so a person can read the matching off the picture.

The same seed always gives the same tiling, in this page and on the command line.

The parts that are easy to get wrong

Rotation changes the problem

A Wang tile is placed as it is. Allowing a tile to turn quietly replaces the tile set with its rotation closure, which is a different set with different answers, and the undecidability result that makes these interesting is about the version that does not turn. Nothing in this program rotates a tile.

A scanline placer can strand itself

Left to right, top to bottom, each cell is constrained by the tile above and the tile to its left. If the set has no tile for some (north, west) pair, the placer eventually reaches that pair and has nowhere to go. The stochastic sets here are complete by construction and the page checks it pair by pair. The Jeandel-Rao set is not complete, strands a naive pass 100 times out of 100, and gets the backtracking solver instead.

Aperiodic is not the same as random

A stochastic two colour tiling is random, and random is not aperiodic. The Jeandel-Rao set of 11 tiles is genuinely aperiodic: it tiles the plane and admits no periodic tiling at all. That was proven by Emmanuel Jeandel and Michael Rao in arXiv:1506.06492, not here. What this program checks is weaker and is stated as such: the set tiles large squares, and an exhaustive search finds no tiling of any torus up to 5 by 5. Both would fail on a mistranscribed digit, and one of them did.

Truchet curves join only under a condition

Cyril Stanley Smith's arcs join because every tile presents an endpoint at all four edge midpoints, so any orientation meets any neighbour. Draw one quarter arc per tile instead and most curves end in mid air. Both are here, because a continuity checker that only ever sees valid input proves nothing. The original diagonal tile has its endpoints at the corners, where four cells meet, and continuity needs every interior vertex to have an even number of line ends. The fields that satisfy that are exactly a[row] xor b[column], and nothing else.
